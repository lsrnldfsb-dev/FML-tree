Family Tree

One-time setup needed. Connect a free database so your whole family can collaborate.

  1. Go to supabase.com and create a free account
  2. Click New Project and wait ~1 minute
  3. Go to Project Settings → API
  4. Copy your Project URL and anon key into public/config.js
  5. In SQL Editor, run the contents of supabase-schema.sql
  6. Commit & push — GitHub Pages will redeploy automatically
